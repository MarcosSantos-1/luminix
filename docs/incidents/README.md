# Registro de incidentes

Quando acontecer algo sério, registrar.

Exemplos:

- dados incorretos;
- vazamento;
- pagamento duplicado;
- produção fora do ar;
- migration problemática;
- perda de arquivo;
- bug grave.

Template:

```text
INC-XXX

Data:

Resumo:

Impacto:

Usuários afetados:

Causa raiz:

Como detectamos:

Como corrigimos:

Como evitar repetição:

Testes adicionados:

Mudanças arquiteturais necessárias:
```

Nunca terminar um incidente apenas com:

"bug corrigido".

O objetivo é impedir reincidência.
