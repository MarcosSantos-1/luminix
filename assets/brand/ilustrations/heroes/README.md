# Originais das capas por categoria

Os oito PNGs foram fornecidos para uso nas vitrines. As versões WebP ficam em
[`apps/web/public/clinic/heroes`](../../../../apps/web/public/clinic/heroes).
A capa de cabeleireiro feminino continua no [inventário da Demonstração 02](../../../demonstracoes/02-cabeleireiro-feminino/README.md).

Massoterapia e quiropraxia compartilham a arte de massoterapia. Sobrancelhas, cílios e piercing
usam as ilustrações de serviço no catálogo e aguardam artes de capa.
