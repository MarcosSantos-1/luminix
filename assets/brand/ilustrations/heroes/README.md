# Originais das capas por categoria

Os dez PNGs foram fornecidos para uso nas vitrines. As versões WebP ficam em
[`apps/web/public/clinic/heroes`](../../../../apps/web/public/clinic/heroes).
A capa de cabeleireiro feminino continua no [inventário da Demonstração 02](../../../demonstracoes/02-cabeleireiro-feminino/README.md).

Massoterapia e quiropraxia compartilham uma capa, assim como sobrancelhas e cílios. Piercing tem capa própria.

Os originais substituídos de estética corporal e as duas versões anteriores de sobrancelhas/cílios ficam em [anteriores](anteriores).
